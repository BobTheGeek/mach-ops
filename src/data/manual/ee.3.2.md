## What it is

Adding two expressions just means collecting the like terms from both. Subtracting one is where people go wrong, because the minus sign in front of the brackets applies to **everything** inside them, not only to the first term.

**Key idea: to subtract an expression, add the opposite of every term inside it. −(2x − 4) is −2x + 4.**

## How to solve it

1. Write both expressions out, each in its own brackets, so you can see exactly what is being added or taken away.
2. If you are subtracting, change it to adding the opposite: flip the sign of **every** term inside the second brackets. Both of them, not just the first.
3. Group the like terms: letters with letters, plain numbers with plain numbers.
4. Add each group and write the result.

## Watch out for

- **Mistake:** flipping only the first term, so (5x + 3) − (2x − 4) comes out as 3x − 1. **Fix:** the minus applies to both. It becomes 5x + 3 − 2x + 4 = 3x + 7.
- **Mistake:** dropping the brackets and changing nothing, so the second expression is added instead of subtracted. **Fix:** brackets after a minus sign are a warning. Nothing leaves them with the sign it went in with.

## Where it shows up

- **Briefing** — the weight difference between two loadouts.
- **Refuel and escort** — fuel on board minus the reserve you must keep.
- **Systems:** Fuel, Weapons.
- **Real aircraft:** if loadout A is 4m + 900 lb and loadout B is 2m + 1,200 lb, the difference is 2m − 300 lb: A is heavier once each store passes 150 lb.
