## What it is

An inequality describes a whole range of allowed values rather than one answer. Minimum safe altitude is not a single height; it is every height at or above a line.

**Key idea: 'at least' means ≥, 'no more than' means ≤. Open circle for < and >, closed circle for ≤ and ≥. Shade toward the solutions.**

## How to solve it

1. Read the words carefully. 'At least' and 'no less than' allow the boundary itself; 'more than' and 'fewer than' do not.
2. Pick the symbol. An 'or equal to' phrase gets the line under the arrow: ≤ or ≥.
3. Draw the circle. Closed if the boundary counts, open if it does not.
4. Shade toward every value that works, and put an arrow on the end to show it keeps going.

## Watch out for

- **Mistake:** flipping the phrase, so 'at least 5' becomes x ≤ 5. **Fix:** 'at least 5' means 5 is the smallest allowed, so x ≥ 5.
- **Mistake:** swapping the circles. **Fix:** closed means the boundary is included. 'At least 5' includes 5, so the circle is filled in.
- **Mistake:** treating it as one answer, so x > 5 becomes x = 5. **Fix:** an inequality has infinitely many answers. 5.1, 6 and 900 all work.

## Where it shows up

- **Briefing** — maximum takeoff weight, minimum landing fuel.
- **Intercept sorties** — the ceiling you must stay under.
- **Systems:** Avionics, Weapons.
- **Real aircraft:** the T-38 tops out around Mach 1.08 at sea level, so any true airspeed x in that regime satisfies x ≤ 1.08 Mach.
