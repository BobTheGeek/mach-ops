## What it is

Two straight lines can do exactly three things: cross once, run parallel forever, or lie on top of each other. That is how many solutions a pair of equations can have.

**Key idea: Different slopes: they cross once, so ONE solution. Same slope, different b: parallel, so NO solution. Same slope AND same b: the same line, so infinitely many.**

## How to solve it

1. Get both equations into y = mx + b. Until they are, you cannot compare them.
2. Compare the SLOPES. Different slopes lean differently, so the lines must cross exactly once.
3. Same slope but a different b means parallel. They never meet, so there is NO solution.
4. Same slope AND the same b is the same line written twice, so every point on it is a solution.

## Watch out for

- **Mistake:** saying parallel lines have one solution. **Fix:** parallel means they never touch. No crossing, no solution.
- **Mistake:** taking a shared slope to mean a shared line. **Fix:** check b as well. Same slope with different intercepts is two lines, not one.

## Where it shows up

- **Briefing** — will two headings ever cross?
- **Sortie** — intercept geometry between your track and the target's.
- **Systems:** Avionics.
- **Real aircraft:** two aircraft on parallel tracks at the same speed never converge, whatever the closure display says.
