## What it is

A function is a rule that never gives you two answers. Put one input in, get exactly one output back.

**Key idea: A function gives exactly ONE output for each input. The same input with two different outputs is not a function. The same output twice is fine.**

## How to solve it

1. List the INPUTS. In a table that is the top row; in a set of pairs it is the first number of each.
2. Look for the same input twice. If one input has TWO different outputs, it is not a function.
3. The same OUTPUT twice is fine. Two aircraft can share a pilot; one aircraft cannot have two.
4. On a graph it is the VERTICAL line test: if a vertical line ever crosses the graph twice, it is not a function.

## Watch out for

- **Mistake:** calling it "not a function" because an output repeats. **Fix:** outputs may repeat as often as they like. Only a repeated INPUT with different outputs breaks it.
- **Mistake:** running a horizontal line test instead. **Fix:** the line is VERTICAL. It asks whether one x has two y's.

## Where it shows up

- **Systems panel** — throttle setting to thrust: one setting, one reading.
- **Hangar** — tail number to the pilot booked on it.
- **Systems:** Engines, Avionics.
- **Real aircraft:** an engine's throttle-to-thrust curve is a function, which is why the same setting gives the same thrust every time.
