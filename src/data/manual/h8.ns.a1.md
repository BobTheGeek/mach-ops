## What it is

A **rational** number is one you can write as a fraction of two whole numbers. Its decimal either ends or repeats. An **irrational** number cannot be written that way at all: its decimal runs forever without ever repeating. π is irrational, and so is √2.

**Key idea: rational numbers can be written as a fraction of integers, and their decimals end or repeat. Irrational decimals never end and never repeat. To turn 0.333… into a fraction, set x = 0.333…, multiply by 10, and subtract.**

## How to solve it

1. To classify a number, ask whether it can be written as a fraction of two whole numbers. A square root is rational only when what is under it is a perfect square: √49 = 7, but √50 is not a whole number.
2. To turn a repeating decimal into a fraction, give it a name: x = 0.333…
3. Multiply by one power of ten for each repeating digit, so the repeating tails line up. One digit needs 10; two digits need 100.
4. Subtract the first line from the second. The tails cancel, leaving a whole number. Divide, then simplify.

## Watch out for

- **Mistake:** marking every square root irrational, so √49 is called irrational. **Fix:** check what is under the root. If it is a perfect square the root is a whole number, and whole numbers are rational.
- **Mistake:** marking a long decimal irrational because it looks endless, so 0.121212… is called irrational. **Fix:** look for a repeat. A decimal that repeats, however long the block, is rational: 0.121212… is 12/99, which is 4/33.
- **Mistake:** multiplying by 10 when two digits repeat. **Fix:** one power of ten per repeating digit. For 0.4545… multiply by 100, not 10, so the 45s line up before you subtract.

## Where it shows up

- **Intercept sorties** — a sensor that repeats a value is reading something exact; one that drifts is not.
- **Refuel and escort** — Mach values written as fractions of Mach 1.
- **Systems:** Radar, Avionics.
- **Real aircraft:** the T-38 is listed at Mach 1.08. That is 27/25, a rational number whose decimal ends. A diagonal across a square apron is a root, and usually is not.
