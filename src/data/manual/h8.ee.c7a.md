## What it is

Not every equation has an answer, and some have every answer. Which one you have shows up the moment the x terms cancel.

**Key idea: if solving leaves x = a number, there is one solution. A false statement like 3 = 5 means no solution. A true statement like 4 = 4 means infinitely many.**

## How to solve it

1. Simplify both sides as far as they go. Distribute across any brackets first, every term inside them.
2. Move the x terms to one side, the way you would for any equation.
3. Look at what is left. If the x terms cancelled and the numbers disagree, the statement is false and nothing works. If they cancelled and the numbers agree, the statement is true and everything works.
4. If an x survived, divide and you have your one solution.

## Watch out for

- **Mistake:** reading x = 0 as no solution. **Fix:** x = 0 is a solution; it says the answer is zero. No solution means no number at all works, which looks like 3 = 5.
- **Mistake:** reading 4 = 4 as no solution. **Fix:** 4 = 4 is true, and it is true whatever x is. That is infinitely many solutions, not none.

## Where it shows up

- **Briefing** — comparing two fuel plans: do they ever cost the same, always, or never?
- **Intercept sorties** — two tracks at the same speed never meet.
- **Systems:** Engines, Avionics.
- **Real aircraft:** two aircraft flying the same speed on parallel tracks stay the same distance apart forever. That is an equation with no solution.
