## What it is

Two-step equations plus the flip rule. Then one more thing: when the answer is a count of real objects, you have to read it back into the world. You cannot load half a missile.

**Key idea: undo addition or subtraction, then multiplication or division, reversing the symbol only when multiplying or dividing by a negative. Then interpret the answer.**

## How to solve it

1. Undo the adding or subtracting first, on both sides, exactly as with an equation.
2. Now divide by the coefficient. If the whole thing is in brackets, divide by the outside number first.
3. Reverse the symbol only if you divided or multiplied by a negative.
4. Read the answer back into the question. If it counts real things, round to the last whole number that still fits — which usually means rounding down.

## Watch out for

- **Mistake:** dividing only the x term and leaving the constant. **Fix:** take the constant off first, then divide everything that is left.
- **Mistake:** missing the flip when the coefficient is negative. **Fix:** check the sign of the divisor before you write the symbol down.
- **Mistake:** reporting 3.5 missiles. **Fix:** you cannot carry half a store. 3.5 means three fit and four do not, so the answer is 3.

## Where it shows up

- **Briefing** — maximum ordnance: 2w + 300 ≤ 1,100.
- **Hangar** — how many upgrades a credit balance covers.
- **Systems:** Weapons, Fuel, Credits ledger.
- **Real aircraft:** if each store weighs 200 lb, the rack weighs 300 lb and the limit is 1,100 lb, then 200s + 300 ≤ 1,100 gives s ≤ 4, so four stores.
