## What it is

A pyramid's net is one base with a ring of triangles folded up round it. The one thing that catches people is which height those triangles use.

**Key idea: S = base area + the triangular faces. Each triangle uses the SLANT height — the distance up the sloping face — not the pyramid's vertical height.**

## How to solve it

1. Count the triangles. A square base has four; a triangular base has three.
2. Work out the base area on its own first.
3. Each sloping triangle uses the SLANT height, the distance from the base edge up the face to the tip. The vertical height is a different, shorter measurement.
4. The sloping faces come to half the base perimeter times the slant. Add the base back on for the total.

## Watch out for

- **Mistake:** using the pyramid's height on the sloping faces. **Fix:** the slant is always LONGER than the height, because it leans. If the question gives you both, the faces want the longer one.
- **Mistake:** forgetting the base. **Fix:** unless the question says "lateral" or "sloping faces only", the base is part of the surface.

## Where it shows up

- **Hangar** — the fabric on a tent hangar.
- **Briefing** — the housing over a radar cone.
- **Systems:** Avionics.
- **Real aircraft:** a pyramidal target marker is covered in sheet, and the sheet is cut to the slant, not to the height.
