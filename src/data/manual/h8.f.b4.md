## What it is

Given a situation, write the rule for it. Find how fast it changes and where it starts, and y = mx + b does the rest.

**Key idea: Rate of change from two points or from the story ('burns 12 L per minute' gives m = −12). The initial value is what you have at time 0. Then y = mx + b.**

## How to solve it

1. Find the RATE first. From a story it is the "per" number; from two points it is the change in y divided by the change in x.
2. Give it a sign. Something running DOWN has a negative rate, however the sentence is worded.
3. Find the START: the value at x = 0. If the table does not go back that far, work backwards from a row you do have.
4. Write y = mx + b, then use it: put an x in to predict a y.

## Watch out for

- **Mistake:** writing a positive rate for something that is going down. **Fix:** burning fuel means m is negative. The number gets smaller, so the rate must be too.
- **Mistake:** using the first row of the table as b. **Fix:** b is the value at x = 0. If the table starts at x = 5, step back five lots of m to get there.

## Where it shows up

- **Briefing** — fuel = 900 − 12t.
- **Sortie HUD** — altitude during a descent.
- **Systems:** Fuel, Avionics.
- **Real aircraft:** the fuel prediction on a flight management system is exactly this model, rebuilt every few seconds.
